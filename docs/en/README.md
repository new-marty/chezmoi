# Dotfiles Documentation

Welcome to the dotfiles documentation. This guide covers all custom commands, tools, and configurations.

## Quick Start

```bash
help          # Show all commands and aliases
keys          # Show keybindings
docs          # Open documentation in editor
tldr <cmd>    # Quick command examples
navi          # Interactive cheat sheets
```

## Keybindings Quick Reference

| Key      | Function                 |
| -------- | ------------------------ |
| `Ctrl+G` | Command templates        |
| `Ctrl+S` | Smart suggestions        |
| `Ctrl+F` | Frequent commands        |
| `Ctrl+N` | Navi cheat sheets        |
| `Ctrl+R` | Peco history search      |
| `Ctrl+H` | Atuin history search     |
| `Ctrl+U` | Recent directories       |
| `Tab`    | fzf-tab completion       |
