# Documentation

How to use what these dotfiles set up. The install steps are in the
[top-level README](../../README.md). A Japanese version is in [docs/ja](../ja/README.md).

In a terminal, `help` prints the custom commands, aliases and keybindings, `keys` prints
the keybindings only, and `docs` opens this folder in your editor.

| Page                                   | Read it to                                                         |
| -------------------------------------- | ------------------------------------------------------------------ |
| [Setup in detail](setup.md)            | opt in to application settings, write machine-local files, change the editor |
| [Aliases](aliases.md)                  | look up a short command                                            |
| [Keybindings](keybindings.md)          | look up a `Ctrl` key in the shell                                  |
| [Shell commands](shell-commands.md)    | use `update-dev`, `fcat`, `cdf`, `mkcd`, `ts2mp4`                          |
| [Git](git.md)                          | see what the shared git config changes, and its aliases            |
| [SSH](ssh-setup.md)                    | add hosts and keys, sign commits with an SSH key                   |
| [Optional tools](tools.md)             | see which tools the dotfiles use and what each one adds            |
