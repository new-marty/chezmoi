# Dotfiles ドキュメント

dotfilesのドキュメントへようこそ。カスタムコマンド、ツール、設定のガイドです。

## クイックスタート

```bash
help          # すべてのコマンドとエイリアスを表示
keys          # キーバインドを表示
docs          # ドキュメントをエディタで開く
tldr <cmd>    # コマンドの簡単な例を表示
navi          # インタラクティブチートシート
```

## キーバインド早見表

| キー     | 機能                 |
| -------- | -------------------- |
| `Ctrl+G` | コマンドテンプレート |
| `Ctrl+S` | スマートサジェスト   |
| `Ctrl+F` | よく使うコマンド     |
| `Ctrl+N` | Navi チートシート    |
| `Ctrl+R` | Peco 履歴検索        |
| `Ctrl+H` | Atuin 履歴検索       |
| `Ctrl+U` | 最近のディレクトリ   |
| `Tab`    | fzf-tab 補完         |
