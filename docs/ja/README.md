# ドキュメント

この dotfiles の導入手順と、用意するものの使い方をまとめている。英語版は [docs/en](../en/README.md) と[リポジトリ直下の README](../../README.md) にある。

ターミナルでは、`help` で自作コマンド、エイリアス、キーバインドの一覧、`keys` でキーバインドだけを表示できる。`docs` はこのフォルダをエディタで開く。

| ページ                                | 読むとき                                                         |
| ------------------------------------- | ---------------------------------------------------------------- |
| [導入と設定の詳細](setup.md)          | 導入する、アプリ設定をオプトインする、マシン固有のファイルを書く、エディタを変える |
| [エイリアス](aliases.md)              | 短縮コマンドを調べる                                             |
| [キーバインド](keybindings.md)        | シェルの `Ctrl` キーを調べる                                     |
| [シェルコマンド](shell-commands.md)   | `update-dev`、`fcat`、`cdf`、`mkcd`、`ts2mp4` を使う             |
| [Git](git.md)                         | 共有の git 設定で何が変わるか、git のエイリアスを確かめる        |
| [SSH](ssh-setup.md)                   | ホストや鍵を足す、SSH 鍵でコミットに署名する                     |
| [任意のツール](tools.md)              | dotfiles が使うツールと、それぞれで何が増えるかを確かめる        |
| [tmux と Vim を覚える](tmux-vim.md)   | ヒントを出す、チートシートを開く・印刷する、エディタで Vim のキーを使う |
