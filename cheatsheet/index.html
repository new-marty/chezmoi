  • サーバーの vi は最小版のことが多い。挿入モードで矢印キーを押すと A B C D が入るので、Esc してから h j k l で動く。vim があればそちらを開く。
  • vim の付いたキーは、Alpine などの busybox 版 vi には無い。

tmux

C-b は Ctrl を押しながら b。離してから次のキー。色は箱の大きさ（セッション ⊃ ウィンドウ ⊃ ペイン）。

さかのぼる・コピーする

C-b [→動くCtrl-uCtrl-d/word→Space選び始め→Enterコピー→C-b ]貼る
途中でやめるときはq

サーバーの tmux は、起動したときの EDITOR か VISUAL に vi が入っていないと emacs 風のキーになる。C-b : setw -g mode-keys vi で切り替えられる。

わからなくなったら

C-b ?キーの一覧（q で閉じる）
C-b /次のキーの意味（3.1 以降）
C-b :コマンドを打つ

何も効かないときは、コピーモードかメニューの中にいる。q か Esc で出る。中で開いた別の tmux に送るときは C-b C-b。
