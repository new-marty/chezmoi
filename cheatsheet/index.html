Vim — サーバーの vi で通じるキー

Esc で「ノーマルモード」に戻ってからキーを打つ。迷ったら Esc を2回。vim の印は Vim が入っているときだけ（busybox の vi には無い）。

Vim の文法: 数 + 動詞 + 範囲

数+動詞 d c y >+範囲 w $ i" ip
dw単語を消す 3dd3行を消す（動詞を2回 = 行全体） ci""…" の中を消して入力へ vim y$行末までコピー .直前の変更をもう一度

d = delete、c = change、y = yank（コピー）。覚えた動詞と範囲は全部組み合わせられる。

①vi file開く（サーバーでは vim でなく vi のことも）
①:w保存
①:q :q!閉じる / 保存せずに閉じる
①:wq ZZ保存して閉じる
②:e file別のファイルを開く
③:sp :vsvim上下 / 左右に分割
③Ctrl-w hjklvim分割の間を移る

困ったら

  • Esc Esc → u で戻す → だめなら :q! で何も保存せず閉じる
  • 画面の下に recording → q。-- INSERT -- → Esc
  • キーの意味を調べる: :help dw（閉じるのは :q）
  • VS Code / Cursor で詰まったら: コマンドパレットの「Vim: Toggle Vim Mode」で一時的に止める Mac

サーバーの vi の実情

  • Debian / Ubuntu の vi は最小版（vim-tiny）のことが多い。入力中の矢印キーで A B C D が入る → Esc してから hjkl。vim があればそちらを使う
  • Alpine やコンテナの vi は busybox 版。① の範囲はおおむね使える。vim の印のキーは無い
  • nano しかなければ EDITOR=vi を待たず nano で直す。練習は手元で

この Mac での助け Mac

  • vimtutor（30分の練習。① の週に1回）、Neovim なら :Tutor
  • Neovim: d g z " などの後に続きのキーが出る（which-key）。w e $ の行き先が薄く出る（:Precognition toggle）
  • Vim: 打ちかけのキーが右下に出る（showcmd）
  • Space+/ でこの手帖を開く

tmux — サーバーの tmux で通じるキー

C-b は Ctrl を押しながら b。いったん離してから次のキー。サーバーのウィンドウ番号は 0 から。

tmux の形: 外の箱と中の箱

セッション⊃ウィンドウ（タブ）⊃ペイン（分割）

ssh が切れても、セッションはサーバーで動き続ける。つなぎ直して tmux a で戻る。

始める・抜ける・戻る（シェルで打つ）

①tmux new -s work名前を付けて始める
①C-b d抜ける（中の作業は動き続ける）
①tmux lsセッションの一覧
①tmux a -t work戻る（a = attach）
②C-b sセッションを選ぶ
②C-b $セッションの名前を変える

ウィンドウ（タブ）

①C-b c新しいウィンドウ
①C-b n C-b p次 / 前のウィンドウ
①C-b 0…9番号のウィンドウへ
②C-b ,名前を変える
②C-b w一覧から選ぶ
②C-b &閉じる（確認あり）

ペイン（分割）

①C-b %左右に分ける
①C-b "上下に分ける
①C-b o次のペインへ
①C-b xペインを閉じる（確認あり）
②C-b ←↑↓→その向きのペインへ
②C-b z今のペインを全画面に / 戻す
③C-b Opt+←↑↓→大きさを変える（Ctrl+矢印は macOS が先に取る）
③C-b !ペインを新しいウィンドウに出す
③C-b { C-b }ペインを入れ替える

さかのぼる・コピー（コピーモード）

②C-b [コピーモードに入る（画面をさかのぼれる）
②qコピーモードを出る
②/ ? n探す（vi キーのとき）
③Space … Enter選んでコピー → C-b ] で貼る

サーバーの tmux が vi キーになるのは、起動したときの EDITOR か VISUAL に vi が含まれるとき。そうでなければ emacs 風。C-b : setw -g mode-keys vi で切り替えられる

②v yMac選ぶ / コピー（Mac のクリップボードへ。素の tmux では v は矩形の切り替え）

調べる

①C-b ?キーの一覧（q で閉じる）
②C-b /3.1+次に押すキーの意味を出す
②C-b < C-b >3.0+ウィンドウ / ペインのメニュー
③C-b :コマンドを打つ（古い tmux でも使える）
③C-b C-b中で開いた tmux（サーバー）に C-b を送る
③tmux -V版を確かめる（3.1 未満は C-b / が無く、3.0 未満はメニューも無い）

この Mac だけの近道 Mac

①Opt+hjklペインを移る（サーバー: C-b o）
①Opt+1…9ウィンドウへ（サーバー: C-b 0 が最初）
①Opt+n Opt+z新しいウィンドウ / 全画面
②Opt+t浮かぶ作業用の端末
②C-b P W S Rペイン / ウィンドウ / セッション / 大きさ用の次の1キー。下の段にヒント
①Opt+/tmux の中で早見表
①Space+/この手帖を開く（英数入力のとき）

困ったら

  • 何も効かない → Esc か q（コピーモードやメニューの中かもしれない）
  • 画面が固まった → Ctrl-q（Ctrl-s で止めた出力を再開）
  • 迷ったら C-b d で抜ける。作業は消えない。tmux a で戻る

  3. VS Code / Cursor の Vim は止めずに使う。詰まったら一時停止して、翌日また入れる
  4. 印が ① で全部付いたら ② の行を増やす
