Vim

Colour shows the mode. Before you type a command, make sure you are in Normal mode (green).

Verb + where type the two keys in a row

Read dw as d + w: delete to the next word. c deletes and leaves you in Insert mode. p pastes what you deleted or copied, x deletes one character, . repeats the last change.

Quit and undo

:wqsave and quit
:q!quit, don't save
uundo
Ctrl-rredo

In an old vi, press u again to redo.

  • On a bare server vi is often a minimal build: arrow keys type A B C D in Insert mode, so press Esc and move with h j k l. Open vim instead if it is there.
  • Keys marked vim are missing from busybox vi (Alpine and many containers).

tmux

C-b means hold Ctrl, press b, let go, then press the next key. Colour shows the level: session ⊃ window ⊃ pane.

Scroll back and copy

C-b [→moveCtrl-uCtrl-d/word→Spacestart selecting→Entercopy→C-b ]paste
To stop without copying, pressq

A server's tmux uses these vi keys only if EDITOR or VISUAL contained vi when it started; otherwise it uses emacs keys. Switch with C-b : setw -g mode-keys vi.

When you are stuck

C-b ?every key (q closes)
C-b /what the next key does (3.1+)
C-b :type a tmux command

If nothing responds, you are probably in copy mode or a menu: press q or Esc. To reach a tmux opened inside this one, press C-b C-b.
