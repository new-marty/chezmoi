Vim

Colour shows the mode. Before you type a command, make sure you are in Normal mode (green).

Verb + where type the two keys in a row

w
next word		$
line end		iwvim
word		i"vim
in "…"		same key
twice
d deletedwd$diwdi"dd
c changecwc$ciwci"cc
y copyywy$yiwyi"yy

Read dw as d + w: delete to the next word. The same key twice works on the whole line: dd deletes it. c deletes and leaves you in Insert mode. p pastes what you deleted or copied, x deletes one character, . repeats the last change.

Quit and undo

:wqsave and quit
:q!quit, don't save
uundo
Ctrl-rredo

In an old vi, press u again to redo.

  • On a bare server vi is often a minimal build: arrow keys type A B C D in Insert mode, so press Esc and move with h j k l. Open vim instead if it is there.
  • Keys marked vim are missing from busybox vi (Alpine and many containers).

tmux

C-b means hold Ctrl, press b, let go, then press the next key. Colour shows the level: session ⊃ window ⊃ pane.

Scroll back and copy

C-b [→moveCtrl-uCtrl-d/word→Spacestart selecting→Entercopy→C-b ]paste
To stop without copying, pressq

A server's tmux uses these vi keys only if EDITOR or VISUAL contained vi when it started; otherwise it uses emacs keys. Switch with C-b : setw -g mode-keys vi.

When you are stuck

C-b ?every key (q closes)
C-b /what the next key does (3.1+)
C-b :type a tmux command

If nothing responds, you are probably in copy mode or a menu: press q or Esc. To reach a tmux opened inside this one, press C-b C-b.

Everyday recipes

Real tasks, key by key. Vim keys are coloured by the mode they leave you in; plain grey means type it as shown.

Vim

Start in Normal mode. vim means Vim rather than a minimal vi.

Change a value

vi nginx.conf→/worker_connEnter→wcw2048Esc→:wq
beforeworker_connections 1024;afterworker_connections 2048;

w steps from the name onto the value; cw replaces just that word.

Comment out a line

/listen 80Enter→I#Esc→:wq
before listen 80;after # listen 80;

I types at the start of the line, whatever the cursor position.

Comment out several linesvim

Ctrl-vjjj→I#Esc

Ctrl-v selects a column; what you type after I appears on every line when you press Esc.

Delete lines

5dd5 lines from hereor:10,20dlines 10–20

Turn on line numbers first if you need them: :set nu

Copy a line, then edit the copy

yyp→wC10.0.0.2;Esc
beforeallow 10.0.0.1;afterallow 10.0.0.1;
allow 10.0.0.2;

p pastes below the cursor (P above). C replaces everything to the end of the line.

Replace everywhere, one at a time

:%s/old/new/gcEnter→answeryornfor each

% means every line, g every match on a line, c asks each time. Drop c to replace them all at once.

Read a log from the end

view app.log→G?ERROREnter→nolderNnewer→:q

view opens read-only. ? searches upwards, so n keeps going back in time.

Saved, but no permissionvim

:w !sudo tee % > /dev/nullEnter→L→:q

For a root file you opened without sudo. L reloads the saved file when Vim warns that it changed.

Throw away your changes

:e!back to the saved fileor:q!just leave

Nothing is written until :w, so either way the file on disk is untouched.

tmux

C-b then the key.

A job that survives logout

tmux new -s deploy→start the job→C-b d→later:tmux a -t deploy

The job keeps running on the server after you detach or the connection drops.

Edit while watching the log

C-b %→tail -f app.log→C-b o→vi app.conf

C-b o switches between the two panes; C-b z zooms the one you are in.

Copy an error from the scrollback

C-b [?errorEnter→Space$Enter→C-b ]

With vi keys: Space starts the selection, $ extends it to the line end, Enter copies.

Type in every pane at once

C-b :setw synchronize-panes on→… thenoff

Handy for running the same command on several servers, each ssh-ed in its own pane.

Name things so you find them

C-b ,windowC-b $session→C-b wpick from the tree

tmux ls and C-b s list sessions by these names.

Close what you no longer need

C-b xpaneC-b &windowanswery→tmux kill-session -t old

exit in the last pane of a window closes it too.
