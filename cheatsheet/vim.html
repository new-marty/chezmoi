Vim: moving and editing

All of these keys work in Normal mode (green).

Moving through a file blue dashes: the part on screen

Verb + where delete d · change c · copy y, then a motion. The same key twice means the whole line.

dw
delete to the next word
proxy_pass backend_server timeout;→proxy_pass timeout;
d$
delete to the end of the line
proxy_pass backend_server timeout;→proxy_pass
dd
delete the whole line
proxy_pass backend_server timeout;→(line removed; p puts it back)
cwapiEsc
change to the end of the word
proxy_pass backend_server timeout;→proxy_pass api timeout;
ci"/srvEscvim
change inside the quotes
root "/var/www";→root "/srv";
yyp
copy the line, paste below
allow 10.0.0.1;→allow 10.0.0.1;
allow 10.0.0.1;

p pastes what was deleted or copied · x deletes one character · . repeats the last change · u undoes it

Vim recipes

Each card: what you want, then the keys in order with what each does, and the screen before and after. Key colours show the mode they leave you in. Start in Normal mode.

Change a value

maxclients 10000 → 20000 in redis.conf

  1. vi redis.confopen the file
  2. /maxclientsEnterjump to the line
  3. wstep onto the value
  4. cw20000Escreplace that word
  5. :wqsave and quit
before
port 6379 maxclients 10000 save 900 1
/maxclients
after
port 6379 maxclients 20000 save 900 1
"redis.conf" written

Comment out a line

turn listen 80 off without deleting it

  1. /listen 80Enterfind the line
  2. I# Esctype at the line start
  3. :wqsave and quit
before
server { listen 80; }
/listen 80
after
server { # listen 80; }
"site.conf" written

Comment out several linesvim

put # in front of three lines at once

  1. Ctrl-vstart a column selection
  2. jjextend it two lines down
  3. I#type at the left edge
  4. Esc# appears on every line
before
listen 80; listen 443; server_name a;
-- VISUAL BLOCK --
after
#listen 80; #listen 443; #server_name a;

Replace everywhere, one at a time

old.lan → new.lan, checking each

  1. :%s/old/new/gcEnter% every line, c ask each time

  3. nskip this one
  4. areplace all the rest

Change when a cron job runs

run the backup at 4:00 instead of 3:00

  1. crontab -eopen your crontab in vi
  2. /backupEnterfind the job
  3. 0wstart of line, then the hour
  4. r4replace 3 with 4
  5. :wqsave; cron installs it
before
# m h dom mon dow cmd 0 3 * * * backup.sh
 
after
# m h dom mon dow cmd 0 4 * * * backup.sh
crontab: installing new crontab
