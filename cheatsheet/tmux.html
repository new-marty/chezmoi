When you are stuck after C-b

?every key (q closes)
/what the next key does (3.1+)
:type a tmux command

Nothing responds? You are in copy mode or a menu: press q or Esc. To reach a tmux opened inside this one, press C-b twice.

tmux recipes

Each card: what you want, the keys in order with what each does, and the screen before and after. C-b … means press C-b, let go, then the key.

A job that survives logout

a deploy keeps running after you disconnect

  1. tmux new -s deploystart a named session
  2. ./deploy.shstart the job
  3. C-b ddetach; the job keeps going
  4. tmux a -t deploylater: back to it
before
$ ./deploy.sh uploading… 42%
[deploy] 0:bash*
after
$ tmux a -t deploy uploading… 87%
[deploy] 0:bash*

Edit while watching the log

the log on the left, the config on the right

  1. C-b %split left | right
  2. tail -f app.logfollow the log in the new pane
  3. C-b omove to the other pane
  4. vi app.confedit there

Copy an error from the scrollback

paste a line from earlier output

  1. C-b [enter copy mode
  2. ?ERROREnterfind the line
  3. Space$select to the line end
  4. Entercopy it
  5. C-b ]paste at the prompt
before
12:01 GET / 12:02 ERROR db timeout $
[2/120]
after

Type in every pane at once

run the same command on three servers

  1. C-b :open the tmux prompt
  2. setw synchronize-panes onEnterpanes now share input
  3. dateEntertyped once, runs in all
  4. … synchronize-panes offback to normal
